Рабочая папка - папка на компьютере, где можно напрямую работать с файлами проекта.

Индекс - промежуточная область, то что отмечено командой git add и что попадает в следующий коммит.

Коммит - фиксированный снимок содержимого индекса в истории репозитория с автором, датой и комментариями.

Git - распределенная система контроля версий, работает локально на компьютере

GitHub - веб-сервис для хранения git репозиториев и совместной работы над проектами
