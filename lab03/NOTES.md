отличие git diff от git show и git log
git diff - показывает разницу, что именно изменилось в файлах, но не показывает историю.
git show - показывает один коммит: данные (автор, дата, сообщение) и изменения.
git log - показывает историю коммитов, без содержимого изменений.

-S"def" ищет коммиты, в которых изменилось количество
вхождений строки "def". Он показал все три коммита, где добавлялась новая функция. 

git blame построчно показывает, какой коммит и какой
автор добавил каждую строк.

git restore — возвращает файл к состоянию последнего коммита. Незакоммиченные правки теряются.
git restore --source= — берёт файл из указанного коммита и кладёт его в рабочую папку.
Что произошло бы с моими правками: все незакоммиченные изменения в файле безвозвратно теряются.
